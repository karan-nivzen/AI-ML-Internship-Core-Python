# Writing First Python Code & Using Online Compilers
## Overview

Before writing first line of Python, we need two things: **code** and an **environment to run it**. This guide walks you through both — explaining why an execution environment matters, how to use online compilers like **JDoodle** to run Python instantly, and why moving to a **local installation** is the natural next step.

---

## Why We Need an Execution Environment

Writing code is only half the job. Machines understand only **machine code**, so our Python code needs an **interpreter** (or compiler) to translate it into something the computer can execute. Whether you use an online editor or a local setup, having the right environment is essential before you can see any output.

---

## Start with an Online Compiler

The easiest way to begin is with an online compiler like **JDoodle** — no downloads, no setup. Just open the site, select Python, and run your code. This lowers the barrier to entry and lets you focus on learning syntax rather than configuring tools.

---

## Python vs. Other Languages

To appreciate Python's simplicity, compare a simple "Hello World" program across languages:

| Language | Verbosity |
|---|---|
| **C** | Verbose — requires headers, main functions, and syntax boilerplate |
| **Java** | Verbose — requires classes and method declarations |
| **VB** | Verbose — requires module and procedure setup |
| **Python** | Minimal — a single `print("Hello World")` line |

Python's clean, readable syntax is one of the biggest reasons beginners find it approachable.

---

## Things to Keep in Mind

- **Use Python 3** — Python 2 is obsolete and no longer supported.
- **Black screen output is normal** — command-line/terminal output is standard for backend code execution. Don't expect graphics right away.
- **The `print()` function** is your first tool for displaying output — simple, but powerful enough to start with.
- **Version awareness matters** — always work with the current, supported version to stay compatible with modern tools and best practices.
